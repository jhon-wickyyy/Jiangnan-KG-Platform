# 江南古典园林知识图谱可视化平台项目背景

## 1. 项目概述

中国古典园林是中国传统文化的重要组成部分，其中江南古典园林以其独特的空间营造方式和自然、人文融合理念，体现了中国传统园林艺术的高度成就。

江南园林通过建筑、水体、山石、植物等多种空间要素的组合，形成了“步移景异”的空间体验。

然而，由于历史变迁、资料散佚以及部分园林消失等原因，大量古典园林的历史信息难以完整保存和系统研究。

因此，如何利用数字化技术对江南古典园林知识进行整理、组织和表达，成为文化遗产保护与数字化研究的重要方向。

------

# 2. 研究背景

## 2.1 江南古典园林知识具有多源异构特点

江南古典园林相关信息来源广泛，主要包括：

- 历史文献；
- 园林记载；
- 古代绘画；
- 建筑资料；
- 测绘数据；
- 研究文献。

这些数据具有以下特点：

- 数据来源不同；
- 信息表达形式不同；
- 数据结构存在差异。

传统数据库通常采用二维表结构，难以有效表达园林实体之间复杂的关联关系。

例如：

一个园林通常与多个建筑、景观元素存在复杂关联：

```
网师园

↓

包含

↓

濯缨水阁

↓

关联

↓

水体空间
```

这种复杂语义关系更适合采用知识图谱技术进行组织和表达。

------

# 3. 知识图谱技术应用背景

知识图谱通过实体（Entity）、属性（Property）和关系（Relationship）对现实世界知识进行结构化表达。

相比传统数据库，知识图谱具有以下优势：

1. 能够表达复杂实体关系；
2. 支持多跳关系查询；
3. 能够发现潜在知识关联；
4. 支持知识网络可视化。

在文化遗产数字化领域，知识图谱已经成为组织多源异构文化数据的重要技术方法。

本项目采用 Neo4j 图数据库构建江南古典园林知识图谱，将园林、建筑、景观等对象进行实体化表达，并通过关系网络描述不同实体之间的关联。

------

# 4. 项目研究基础

## 4.1 江南古典园林知识图谱原型库建设

目前项目已经完成江南古典园林知识图谱原型库建设。

当前数据库包含约 30 个典型江南古典园林案例。

知识图谱主要包含：

- 园林实体；
- 建筑实体；
- 景观实体；
- 实体之间的关联关系。

数据库采用 Neo4j 图数据库进行存储。

------

## 4.2 知识图谱建模

项目针对江南古典园林的特点，对园林知识进行结构化组织。

目前已经完成：

- 园林实体构建；
- 建筑节点构建；
- 景观节点构建；
- 实体关系建立。

形成如下知识关联体系：

```
园林

↓

建筑

↓

景观

↓

相关知识节点
```

通过图结构表达园林空间组成和知识关联关系。

------

# 5. 平台建设需求

虽然知识图谱能够有效组织园林知识，但是直接访问图数据库需要一定的数据查询和编程能力。

因此，需要进一步开发基于 Neo4j 的知识图谱可视化平台。

平台目标是将数据库中的节点和关系以更加直观的方式展示，使用户能够方便地：

- 浏览园林知识；
- 查询实体节点；
- 查看实体关系；
- 探索知识网络。

------

# 6. 平台建设意义

## 6.1 提升园林知识组织能力

通过知识图谱技术，将分散的园林知识转化为结构化知识网络，提高园林信息组织效率。

------

## 6.2 提升文化遗产数字化研究能力

通过图数据库和可视化技术，为江南古典园林研究提供新的数字化分析工具。

------

- AI辅助园林分析。

# 8. 项目总结

本项目以江南古典园林为研究对象，利用知识图谱技术对园林知识进行结构化组织，并基于 Neo4j 图数据库开发知识图谱可视化交互平台。

通过实现知识浏览、关系探索和智能查询，为江南古典园林数字化保护、研究和应用提供基础支撑。
